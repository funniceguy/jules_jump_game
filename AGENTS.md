# Jump Game Project Instructions

This project is a Jump Game built with TypeScript, Phaser, and Vite.

## Tech Stack
- **Language**: TypeScript
- **Game Engine**: Phaser
- **Bundler**: Vite
- **Package Manager**: npm

## Development Guidelines
- Follow TypeScript best practices.
- Use `npm` for dependency management.
- Ensure the game is playable in a web browser.
- Tests should be added where appropriate.

## Verification
- Verify frontend changes using Playwright or by taking screenshots of the running application.
